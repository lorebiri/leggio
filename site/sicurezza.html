Avvisi di sicurezza

Windows o macOS dicono che Leggio «potrebbe non essere sicuro»? Ecco perché, e cosa fare.

In breve: Leggio non ha una firma digitale a pagamento ed è un programma nuovo, quindi i sistemi avvisano per prudenza. Non vuol dire che contenga un virus. Qui sotto trovi il perché, la guida passo per passo per il tuo computer e il modo per controllare tu stesso che il file sia quello giusto.

Windows 10 e 11 macOS Linux

Perché compare l'avviso

Leggio non è firmato digitalmente

Windows e macOS si fidano di più dei programmi con una firma digitale: un certificato a pagamento, da rinnovare ogni anno, che dice chi ha pubblicato il programma. Leggio è gratuito e fatto da una persona sola, e questo costo annuale per ora non è previsto: per questo gli avvisi possono comparire, e conviene sapere come procedere.

È un programma nuovo, senza «reputazione»

Microsoft e Apple tengono conto anche di quante persone hanno già scaricato e usato un programma. Un programma nuovo, scaricato da poche persone, non ha ancora questa reputazione: per prudenza il sistema avvisa, anche se il file è innocuo. Con il tempo, man mano che i download aumentano, la reputazione migliora e gli avvisi della finestra blu di Windows di solito diminuiscono. Su macOS l'avviso alla prima apertura resta comunque.

L'avviso non è una diagnosi

L'avviso significa «non so chi l'ha fatto», non «ho trovato un virus». Se un antivirus trova davvero qualcosa di dannoso, il messaggio è diverso e parla di una minaccia rilevata: in quel caso leggi qui.

Non devi fidarti sulla parola: puoi controllare

  • Il codice è aperto: chiunque può leggerlo sul repository di Leggio su GitHub.
  • I file da installare li costruisce GitHub, in automatico, a partire da quel codice: i passaggi sono pubblici nel file release.yml.
  • Ogni file ha la sua impronta SHA-256, pubblicata accanto al pulsante di download e nel file SHA256SUMS.txt: se l'impronta del file che hai scaricato è identica, il file è proprio quello pubblicato. Ecco come si controlla.
  • Leggio non chiede la password di amministratore su Windows: si installa solo per il tuo utente.

La regola d'oro: scarica Leggio solo dalla pagina ufficiale (lorebiri.github.io/leggio) o da GitHub Releases. Se trovi Leggio su altri siti, anche se sembra uguale, non usarlo: i passi di questa pagina valgono solo per il file ufficiale.

Cosa fare, passo per passo

Apri la guida del tuo computer: se la pagina ha riconosciuto il sistema, l'ha già aperta per te. Le figure sono riproduzioni semplificate: i colori e la disposizione delle finestre vere cambiano da una versione all'altra, ma i nomi dei pulsanti evidenziati sono quelli da cercare. Il numero sul pulsante corrisponde al passo.

Windows 10 e 11

il tuo sistema

A Al download: l'avviso del browser

Alcuni browser fermano i file poco scaricati e li mettono in attesa nell'elenco dei download. Il file non è stato eliminato: devi solo dire che vuoi tenerlo.

Microsoft Edge

Messaggio: «Leggio-…-installer.exe non viene scaricato comunemente…»

  1. Nel pannello dei download, accanto al file, premi … (Altre azioni).
  2. Scegli Mantieni.
  3. Nella finestra che si apre premi Mostra altro.
  4. Premi Mantieni comunque.

Non vedi il pannello? Premi Ctrl + J.

Chrome

Chrome può segnalare il file come «file sospetto», cioè insolito o poco conosciuto.

  1. Apri l'elenco dei download (Ctrl + J).
  2. Accanto al file scegli Scarica file sospetto (nelle versioni meno recenti il pulsante si chiama Mantieni).

Se invece Chrome scrive che il file è pericoloso o che è stato trovato un virus, fermati: scarica di nuovo da questa pagina e controlla l'impronta.

Altri browser

I passi sono simili: cerca il file nell'elenco dei download e la voce per tenerlo («Mantieni», «Consenti il download» o simili). Se non c'è nessuna voce per proseguire, prova a scaricare dalla pagina ufficiale su GitHub.

B All'avvio: «Windows ha protetto il PC»

Quando apri il file scaricato, Windows può mostrare una finestra blu con il titolo «Windows ha protetto il PC»: è il filtro SmartScreen di Microsoft Defender, che avvisa per i programmi senza firma o con poca reputazione.

  1. Premi il link Ulteriori informazioni (in alcune versioni: Maggiori informazioni), sotto il testo.
  2. Controlla che il nome dell'app sia Leggio-… e premi Esegui comunque.

Serve una volta sola per ogni file scaricato. Non serve la password di amministratore. Se il pulsante Esegui comunque non compare, il computer è probabilmente gestito da un ufficio informatico che non permette programmi non firmati: chiedi a loro.

C Se Leggio viene bloccato da «Controllo intelligente delle app»

Solo su Windows 11, e solo se è attivo. Il Controllo intelligente delle app (in inglese Smart App Control; in alcune schermate «Controllo app intelligente») blocca i programmi senza firma e, a differenza della finestra blu, non ha un pulsante per proseguire: Microsoft stessa spiega che oggi non si può fare un'eccezione per una singola app.

Cosa puoi fare
  • Sul computer dell'ufficio: non cambiare nulla e chiedi all'ufficio informatico, che può decidere come autorizzare Leggio sui computer che gestisce.
  • La versione portatile non aiuta: anche lei non è firmata e viene bloccata allo stesso modo.
  • Usa Leggio su un altro computer dove il Controllo intelligente delle app è spento (succede spesso: Windows lo spegne da solo su molti computer) o su un Mac o Linux.
  • Sul tuo computer, se decidi tu, puoi spegnerlo: Sicurezza di Windows → Controllo app e browser → Impostazioni di Controllo intelligente delle app → Disattivato.
Prima di spegnerlo, sappi che…
  • Vale per tutti i programmi, non solo per Leggio: togli una protezione in più al computer. L'antivirus e la finestra blu restano attivi.
  • Nelle versioni recenti di Windows 11 si può riattivare dalla stessa pagina; nelle versioni meno aggiornate, una volta spento, per riaccenderlo bisognava reimpostare o reinstallare Windows. Se non sei sicuro, non spegnerlo.
  • Non scaricare versioni «sbloccate» di Leggio da altri siti e non usare programmi che promettono di aggirare le protezioni di Windows.

D Se l'antivirus mette il file in quarantena

Alcuni antivirus, anche i più diffusi tra quelli gratuiti, trattano con sospetto tutti i programmi nuovi e senza firma: possono bloccarli, spostarli in «quarantena» o cancellarli. A volte si tratta di un falso positivo, ma va controllato.

  1. Non spegnere l'antivirus e non aprire il file finché non hai controllato.
  2. Scarica di nuovo Leggio da questa pagina o da GitHub Releases e controlla l'impronta SHA-256.
  3. Se l'impronta è identica, il file è quello pubblicato: puoi ripristinarlo dalla quarantena del tuo antivirus o aggiungere un'eccezione solo per quel file. Con l'antivirus di Windows: Sicurezza di Windows → Protezione da virus e minacce → Cronologia protezione, apri la voce di Leggio e scegli di ripristinarlo o consentirlo. Con gli altri antivirus la voce si chiama di solito «Quarantena»; i nomi dei pulsanti cambiano da un prodotto all'altro.
  4. Segnala il falso positivo al produttore dell'antivirus (quasi tutti hanno un modulo apposta) e, se ti va, scrivici su GitHub: ci aiuta a farlo correggere per tutti.
  5. Se l'impronta è diversa: cancella il file, non aprirlo e avvisaci.

macOS (Sonoma, Sequoia e successivi)

il tuo sistema

0 Prima: scegli il file giusto per il tuo Mac

Mac con chip Apple (M1, M2, M3, M4…)

Scarica Leggio-…-mac-arm64.dmg.

Mac con processore Intel

Scarica Leggio-…-mac-x64.dmg.

Non sai quale hai? Menu Apple (la mela in alto a sinistra) → Informazioni su questo Mac: se leggi «Chip» seguito da Apple M… è un Mac con chip Apple; se leggi «Processore» seguito da Intel è un Mac Intel. La versione Intel funziona anche sui Mac con chip Apple, ma più lenta; la versione per chip Apple non funziona sui Mac Intel.

1 Il primo avviso: «Apple non può verificare…»

  • Apri il file .dmg e trascina Leggio nella cartella Applicazioni.
  • Apri Leggio dalla cartella Applicazioni.
  1. Compare un avviso: Apple non può verificare che Leggio sia privo di malware (nelle versioni meno recenti: «non può essere aperto perché lo sviluppatore non può essere verificato»). Premi Fine, non Sposta nel Cestino.

Se il messaggio dice invece che Leggio «è danneggiato», il file probabilmente non è stato scaricato bene: cancellalo, scaricalo di nuovo e controlla l'impronta.

2 Autorizza Leggio in «Privacy e sicurezza»

  1. Menu Apple → Impostazioni di Sistema → nella barra laterale Privacy e sicurezza (forse devi scorrere la barra).
  2. Scorri fino in fondo, alla sezione Sicurezza: c'è una riga che parla di Leggio bloccato. Premi Apri comunque.
  3. Compare di nuovo l'avviso: questa volta scegli Apri (in alcune versioni il pulsante si chiama Apri comunque).
  4. Conferma con la password del Mac (quella con cui accedi) o con il Touch ID, poi OK.

Il pulsante Apri comunque resta disponibile per circa un'ora dopo il tentativo di apertura: se non lo vedi, apri di nuovo Leggio e ripeti. Fatto una volta, Leggio si apre con il doppio clic come le altre app. Dopo ogni aggiornamento di Leggio potrebbe servire ripeterlo.

E il vecchio «clic destro → Apri»?

Fino a macOS 14 Sonoma bastava fare clic destro (o Ctrl + clic) sull'app e scegliere Apri, poi ancora Apri. Da macOS 15 Sequoia questo trucco non basta più: Apple ha deciso che si passa sempre da Impostazioni di Sistema → Privacy e sicurezza. La strada qui sopra funziona su tutte le versioni recenti.

Per esperti: togliere la «quarantena» dal Terminale

In alternativa ai passi 2–5, dopo aver copiato Leggio in Applicazioni puoi togliere l'attributo di quarantena che macOS mette sui file scaricati:

xattr -dr com.apple.quarantine /Applications/Leggio.app

Attenzione: così salti del tutto il controllo di macOS per quell'app. Fallo solo con il file ufficiale e dopo aver controllato l'impronta. Non incollare mai nel Terminale comandi trovati su siti che non conosci.

Linux (AppImage)

il tuo sistema

Su Linux non ci sono avvisi come su Windows e macOS, ma il file .AppImage appena scaricato non è ancora «eseguibile»: va reso tale una volta. Se l'AppImage non è ancora pubblicata, la pagina di download lo dice.

1 Rendi eseguibile l'AppImage

Con il gestore dei file
  1. Clic destro sul file Leggio-…-linux-x86_64.AppImage → Proprietà.
  2. Nella scheda Permessi attiva Consenti di eseguire il file come programma. Il nome cambia secondo il desktop e la versione: per esempio «Eseguibile come programma».
  3. Chiudi e apri il file con un doppio clic.
Oppure dal terminale
chmod +x ~/Scaricati/Leggio-*-linux-x86_64.AppImage
~/Scaricati/Leggio-*-linux-x86_64.AppImage

Se il sistema è in inglese la cartella è ~/Downloads.

2 Se non si apre: manca libfuse2

Le AppImage hanno bisogno della libreria FUSE 2. Se non parte, o dal terminale vedi un errore che cita libfuse.so.2, installala:

Ubuntu 24.04 e successivi
sudo apt install libfuse2t64
Ubuntu 22.04, Debian, Mint
sudo apt install libfuse2
Fedora
sudo dnf install fuse-libs

Su Ubuntu non installare il pacchetto chiamato solo fuse: può togliere componenti di sistema.

Controlla che il file sia quello giusto (SHA-256)

L'impronta SHA-256 è una sequenza di 64 caratteri calcolata dal contenuto del file: se cambia anche un solo byte, cambia tutta. Calcola l'impronta del file che hai scaricato e confrontala con quella pubblicata accanto al pulsante di download o nel file SHA256SUMS.txt della versione su GitHub. Devono essere identiche (maiuscole e minuscole non contano).

Windows

  1. Apri il menu Start, scrivi PowerShell e premi Invio.
  2. Copia questo comando, incollalo con il tasto destro del mouse e premi Invio:
Get-FileHash "$env:USERPROFILE\Downloads\Leggio-*.exe" -Algorithm SHA256

L'impronta è nella colonna Hash. Se hai salvato il file altrove, cambia il percorso. Dal Prompt dei comandi va bene anche certutil -hashfile "percorso\del\file.exe" SHA256.

macOS

  1. Apri il Terminale (Launchpad → Altro → Terminale, oppure cercalo con Spotlight).
  2. Copia il comando, incollalo e premi Invio:
shasum -a 256 ~/Downloads/Leggio-*.dmg

Se nella stessa cartella c'è anche SHA256SUMS.txt: cd ~/Downloads && shasum -a 256 -c SHA256SUMS.txt --ignore-missing scrive «OK» accanto ai file giusti.

Linux

  1. Apri il terminale.
  2. Copia il comando, incollalo e premi Invio:
sha256sum ~/Scaricati/Leggio-*.AppImage

Con SHA256SUMS.txt nella stessa cartella: sha256sum -c SHA256SUMS.txt --ignore-missing.
